# Contributing

RealSettle is currently in an early grant/incubation stage.

Useful contribution areas include:

- lifecycle-state design for tokenized funds and private credit;
- administrator/custodian attestation schemas;
- EVM integration adapters;
- Pharos-specific deployment/integration work;
- security review and adversarial tests;
- reconciliation/event-indexing services.

Before proposing a large change, open an issue describing the operational problem being solved and the trust assumptions introduced.

All contract changes should include tests covering success, authorization, replay/freshness, and failure paths.
